# StudyOS

Учебная операционная система с монолитным ядром на Python 3.10+ и SQLite.

## Описание

StudyOS - учебный проект, реализующий базовые подсистемы управления ресурсами вычислительной системы:

- управление процессами;
- управление памятью;
- файловая система на SQLite;
- разграничение прав пользователей;
- командная оболочка (shell);
- подсистема журналирования системных вызовов;
- планировщик процессов (FCFS, Round Robin, приоритетный).

Реальная работа с аппаратным обеспечением заменена программными заглушками.

## Требования

- Python 3.10+
- SQLite3 (встроен в Python)
- Linux, macOS или Windows

Дополнительные библиотеки не нужны - используются только встроенные модули:

- `sqlite3`
- `hashlib`
- `os`
- `sys`
