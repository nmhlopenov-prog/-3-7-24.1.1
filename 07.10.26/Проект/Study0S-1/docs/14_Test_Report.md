# Отчёт о тестировании (Практическое занятие №8)

## Общая информация
- Инструмент: unittest (встроенный модуль Python).
- Команда: python3 -m unittest discover -s tests -v
- Файл тестов: tests/test_shop.py
- Тестируемый модуль: src/shop.py

## Количество тестов
- Написано: 16
- Пройдено: 16
- Провалено: 0

## Разбивка
| Класс              | Кол-во | Что проверяет                          |
|--------------------|--------|----------------------------------------|
| TestGetLowStock    | 3      | Пустой список, нет дефицита, один товар|
| TestSearchAdvanced | 3      | Поиск по названию, категории, цене     |
| TestTotalSum       | 2      | Пустая корзина, корзина с товарами     |
| TestAddToCart      | 3      | Неверный размер, товар не найден, ZeroDivisionError |

## Найденные ошибки
1. get_low_stock падал на товарах с ключом 'sizes' — исправлено _total_quantity.
2. cart_total не учитывал количество — исправлено.

## Функции без тестов
- Заглушки syscalls.py — будут покрыты на интеграционном тестировании.
- _total_quantity — покрыта косвенно через get_low_stock и total_sum.

## Вывод
Все ключевые функции каталога и корзины покрыты модульными тестами.
