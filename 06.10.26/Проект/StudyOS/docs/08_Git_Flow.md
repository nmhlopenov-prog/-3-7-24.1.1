# Схема ветвления Git Flow для StudyOS

## Основные ветки
- main — стабильная версия продукта.
- develop — интеграция новых функций.

## Вспомогательные ветки
- feature/<название> — отдельная функция.
- hotfix/<название> — срочное исправление ошибки.

## Схема

main ────●────────────●────────────●────►
          \          /              \
           \        /                \
develop ────●──●───●────●───●───●─────●──►
             \    /      \ /     \   /
              ●──●        ●       ●─●
           feature/     feature/  hotfix/
           low-stock    total-v1  cart-total
