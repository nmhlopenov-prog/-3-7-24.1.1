# Product Backlog — проект «СпортТовары»

## US-1. Товары с низким остатком
**Как** менеджер магазина, **я хочу** видеть список товаров с низким остатком,
**чтобы** вовремя заказать новую партию.

**Критерии приёмки:**
- Отображаются товары, у которых суммарное количество <= 3.
- Список отсортирован по возрастанию количества.
- Если таких товаров нет — выводится сообщение «Нет товаров с низким остатком».

**Оценка:** 3 story points
**Приоритет:** Высокий

## US-2. Поиск товаров по названию и бренду
**Как** менеджер, **я хочу** искать товары по названию и бренду,
**чтобы** быстро находить нужную позицию.

**Критерии приёмки:**
- Поиск работает по подстроке без учёта регистра.
- Можно комбинировать фильтры: название, бренд, категория.
- Результаты выводятся в виде таблицы.

**Оценка:** 5 story points
**Приоритет:** Высокий

## US-3. Аналитика по категориям
**Как** менеджер, **я хочу** видеть аналитику по категориям,
**чтобы** понимать, какие группы товаров наиболее востребованы.

**Критерии приёмки:**
- Формируется словарь {категория: количество товаров}.
- Выводится общее число позиций и суммарный остаток.
- Результат сохраняется в отчёт (Markdown).

**Оценка:** 5 story points
**Приоритет:** Средний

## US-4. Оформление заказа и сохранение в JSON
**Как** менеджер, **я хочу** оформлять заказ и сохранять его в JSON,
**чтобы** фиксировать историю продаж.

**Критерии приёмки:**
- Заказ содержит: id, дату, список товаров, итоговую сумму.
- Файл orders.json создаётся, если его нет.
- Новый заказ добавляется в существующий файл без перезаписи.

**Оценка:** 8 story points
**Приоритет:** Высокий

## US-5. Журнал действий
**Как** менеджер, **я хочу** видеть журнал действий,
**чтобы** отслеживать, кто и что менял в системе.

**Критерии приёмки:**
- Каждое действие (создание, изменение, удаление) пишется в лог.
- Лог хранится в файле actions.log.
- Записи содержат дату, пользователя и тип операции.

**Оценка:** 3 story points
**Приоритет:** Средний

## US-6. Добавление нового товара
**Как** менеджер, **я хочу** добавлять новые товары,
**чтобы** расширять ассортимент магазина.

**Критерии приёмки:**
- Форма запрашивает: название, бренд, категорию, цену, количество.
- Проверяется, что цена и количество — положительные числа.
- Новый товар сохраняется в общий список products.

**Оценка:** 2 story points
**Приоритет:** Высокий

## US-7. Редактирование товара
**Как** менеджер, **я хочу** редактировать товар,
**чтобы** исправлять ошибки и обновлять цены.

**Критерии приёмки:**
- Можно изменить любое поле товара по его id.
- Изменения сохраняются в общем списке.
- В журнал пишется запись об изменении.

**Оценка:** 3 story points
**Приоритет:** Средний

## US-8. Удаление товара
**Как** менеджер, **я хочу** удалять товары,
**чтобы** убирать позиции, снятые с продажи.

**Критерии приёмки:**
- Удаление по id с подтверждением.
- Если товара нет — выводится сообщение об ошибке.
- В журнал пишется запись об удалении.

**Оценка:** 2 story points
**Приоритет:** Низкий

## US-9. Экспорт списка товаров в CSV
**Как** менеджер, **я хочу** экспортировать товары в CSV,
**чтобы** открывать их в Excel.

**Критерии приёмки:**
- Файл products.csv создаётся в папке export/.
- Первая строка — заголовки столбцов.
- Кодировка UTF-8 с BOM (для корректного открытия в Excel).

**Оценка:** 3 story points
**Приоритет:** Низкий

## US-10. Справка по командам
**Как** менеджер, **я хочу** видеть справку по командам,
**чтобы** быстро вспоминать синтаксис.

**Критерии приёмки:**
- Команда help выводит список всех доступных команд.
- Для каждой команды — краткое описание.
- Вывод форматируется в виде таблицы.

**Оценка:** 1 story point
**Приоритет:** Низкий

## US-11. Сортировка товаров по цене
**Как** менеджер, **я хочу** сортировать товары по цене,
**чтобы** видеть самые дешёвые и самые дорогие позиции.

**Критерии приёмки:**
- Сортировка по возрастанию и по убыванию.
- Параметр sort задаётся в команде.
- Сортировка работает совместно с фильтрами.

**Оценка:** 2 story points
**Приоритет:** Средний

## US-12. Подсчёт итоговой стоимости склада
**Как** менеджер, **я хочу** видеть итоговую стоимость склада,
**чтобы** оценивать оборотные средства.

**Критерии приёмки:**
- Считается сумма (цена * количество) по всем товарам.
- Выводится общая стоимость и разбивка по категориям.
- Результат можно сохранить в отчёт.

**Оценка:** 3 story points
**Приоритет:** Высокий
