Цель и задачи проекта

Цель

Разработать консольное приложение на Python для управления магазином спортивных товаров.

Задачи

  • Реализовать каталог товаров
  • Реализовать корзину покупателя
  • Реализовать оформление заказов
  • Реализовать аналитику продаж
  • Написать модульные тесты (unittest)
  • Оформить документацию в Markdown
